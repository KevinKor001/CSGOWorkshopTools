# CSGOWorkshopTools
a tooling suite to provide tools to create csgo stuff... idk

- - -

mimick the modern Source 2 content creation tools to CS:GO.

this is a application built with Godot that abstracts away the technical aspect, and file conversions. It should give creators an intuitive drag-and-drop workspace with hot-reloading to modify game assets—like skins, stickers, and music kits—on the fly.

Key Features i plan:
 - Source 2 Style Hot Reloading: Modify your raw assets and see them update instantly without having to manually restart every time.

 - SimpleWorkflow: Select PNGs, WAVs, or MP3s straight into the editor. The the app handles all background dir managment, conversions, and updating automatically.

# Getting Started
Prerequisites
CS:GO / Source SDK Installed: Ensure you have CS:GO and Source SDK Base 2007 (App ID 745) installed via Steam.
(if you dont have the SDK you will be prompted to install it)

Steam Running: Required for... well literarilly every thing.

Installation:
Build it first... or Download the latest release binary for your OS (Windows or Linux) from the Releases tab if it exists yet.

Extract the archive to the ROOT if your CSGO FOLDER! (specifically inside `common/csgo legacy`).

Launch CSPlus Workshop tools (please it needs a better name)
